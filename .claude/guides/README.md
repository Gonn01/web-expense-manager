# Guías de desarrollo

Guías para trabajar en los tres proyectos de la Plataforma de Gestión de Deudas. Leé la del proyecto que vayas a tocar **antes** de escribir código; si el cambio cruza proyectos, leé las de todos los afectados.

| Guía | Cuándo leerla |
| --- | --- |
| [arquitectura-flutter.md](arquitectura-flutter.md) | Cualquier cambio en `d:\proyectos_flutter\app_expense_manager` |
| [arquitectura-web.md](arquitectura-web.md) | Cualquier cambio en `web-plataformas-de-desarrollo` (este repo) |
| [arquitectura-api.md](arquitectura-api.md) | Cualquier cambio en `d:\proyectos_node\api-plataformas-desarrollo` |
| [documentacion.md](documentacion.md) | Al terminar cualquier cambio: qué documentación y qué guías hay que actualizar |

Qué describe cada cosa:

- **Estas guías** — *cómo* se construye: capas, convenciones, checklists, trampas.
- **[`docs/`](../../docs/)** — *qué* hace el sistema: requerimientos funcionales, no funcionales, casos de uso y diagramas.
- **`CLAUDE.md`** de cada repo — resumen operativo de ese repo (comandos, estructura) y las reglas transversales.
